# Heimdall 0.2.1 Alpha 1 Release Notes

Release tag: `v0.2.1-alpha.1`

[English](#english) | [简体中文](#简体中文)

## English

### Update Guidance

- Install `0.2.1-alpha.1` directly over an existing official Heimdall Alpha. Do not uninstall first unless troubleshooting requires it; uninstalling removes local App data.
- Export important Profiles before updating and keep the `.heimdall-profile` bundles outside the App until the update has been checked.
- This update does not automatically request Accessibility or Shizuku permission. Enable only the capabilities you need under Getting Started or Connection & Permissions.

### Highlights

- Added a lightweight, skippable Welcome and First Setup checklist. It reuses the existing Profile create/import flows, reports live Basic Touch and Advanced Controls readiness, and remains available later under Settings > Getting Started.
- Reworked Connection & Permissions around additive capabilities. Accessibility-backed Basic Touch and Shizuku-backed Advanced Controls are independent; Advanced Controls now reports stopped, authorization-required, authorized, preparing, ready, and recoverable service-interruption states.
- Added Profile-aware game context support for supported emulator routes while preserving conservative switching and explicit Profile Save. Heimdall stores opaque structured identities rather than raw ROM paths or content URIs.
- Expanded Canvas from static images to local GIF, animated WebP, and muted looping MP4 media. Dynamic media remains Profile-owned, lifecycle-bounded, limited to one dynamic Canvas per Profile, and included in validated Profile bundles.
- Improved Interactive Map browsing with retained Mobile/Desktop identity, authenticated session continuity, text-input focus handling, a compact loading/status toolbar, and mandatory external-browser fallback.
- Improved lower-screen stability across companion relaunch, upper-display focus handoff, Grid-editor close, unresolved Grid drafts, and Shizuku UserService replacement or reinstall.
- Fixed stale automatic App matching after the bound App exits, preserved Unicode letters and digits in exported Profile filenames, and refined Settings layout, typography, first-setup text fit, and Macro numeric controls for the Thor lower screen.

### Verification Scope

- The cumulative feature baseline passed Debug and unsigned Release assembly, Debug Android-test APK compilation, Android Lint, registered-baseline verification, public-source boundary checks, bilingual resource parity, and explicit inspection confirming that the retired ROM Context Probe is absent from the normal source and Debug APK.
- Recorded owner-operated AYN Thor checks cover animated Canvas import/playback/lifecycle and Profile-bundle recovery; Startup Readiness and First Setup; Accessibility/Shizuku independence; Advanced Controls permission and service states; native/Xbox/no-controller recording and replay; Precision Aim, Right Stick, Enhanced Touch, Virtual Mouse, PC Keyboard, and supported automatic game recognition smoke paths; Settings presentation; and Macro stepper readability.
- Build/static results and earlier Debug APK checks do not accept the real-signed `0.2.1-alpha.1` candidate. Before publication, the exact signed APK must still pass the release-specific Thor update/install, launch, Profile migration, permission, input, Canvas, and cleanup matrix.

### Known Limitations

- Heimdall targets AYN Thor and does not guarantee compatibility with every firmware, controller mode, game, emulator, PC streaming client, or other dual-screen device.
- Automatic emulator Profile matching remains conservative. RetroArch is a candidate route whose external-launch identity may remain unknown until RetroArch writes current history; Heimdall does not treat stale history, menu interaction, or arbitrary Accessibility text as proof. PPSSPP Gold and longer Eden/keyboard-residency coverage remain less tested than the recorded core smoke paths.
- Advanced Controls require Shizuku to be installed, running, and authorized. Heimdall does not automatically request that permission, and unavailable native features fail closed instead of silently changing semantics.
- GIF and animated WebP require Android 9 or newer. MP4 is muted and loops. Dynamic Canvas files are limited to 50 MiB and one dynamic Canvas per Profile; APNG is not supported.
- PC Keyboard uses a fixed US ANSI layout and is active-play PC input, not Android text entry. Android streaming clients may not forward external Meta/Win input; use the client's built-in keyboard when Win is required.
- One live magnifier is supported per Profile, and magnification cannot share MediaProjection with recording.
- Android platform backup remains disabled. Keep exported Profile bundles outside the App before uninstalling or replacing device data.

## 简体中文

### 更新说明

- 可将 `0.2.1-alpha.1` 直接覆盖安装到现有 Heimdall 官方 Alpha。除非排障需要，请勿先卸载；卸载会清除 App 本地数据。
- 更新前请导出重要 Profile，并将 `.heimdall-profile` 迁移包保存在 App 外部，直到确认更新正常。
- 本次更新不会自动请求无障碍或 Shizuku 权限。请在“初始设置”或“连接与权限”中仅开启自己需要的能力。

### 主要改进

- 新增轻量、可跳过的 Welcome 与 First Setup 清单。它复用现有 Profile 创建/导入流程，实时显示基础触控和高级控制状态，并可随时从“设置 > 初始设置”重新进入。
- 将“连接与权限”改为能力叠加模型。基于无障碍的基础触控与基于 Shizuku 的高级控制相互独立；高级控制会明确显示 Shizuku 停止、需要授权、已授权、准备中、已就绪以及服务中断后的可恢复状态。
- 为支持的模拟器路线加入 Profile 级游戏上下文识别，同时保留保守切换与明确保存边界。Heimdall 只保存不透明的结构化身份，不保存原始 ROM 路径或 content URI。
- Canvas 从静态图片扩展到本地 GIF、动态 WebP 和静音循环 MP4。动态媒体仍归当前 Profile 所有，遵守页面/前后台生命周期，每个 Profile 最多一个动态 Canvas，并纳入经过校验的 Profile Bundle。
- 改进 Interactive Map：保留移动版/桌面版身份和登录会话，正确处理文字输入焦点，使用紧凑的加载/状态工具栏，并始终保留外部浏览器回退。
- 改进 Companion 重启、上屏焦点交还、Grid 编辑器关闭、未处理 Grid 草稿，以及 Shizuku UserService 替换/重装过程中的下屏稳定性。
- 修复绑定 App 退出后的陈旧自动匹配；Profile 导出文件名现在保留 Unicode 字母和数字；同时优化设置页层级、字体路径、首次设置文字适配和 Thor 下屏上的宏数字步进器。

### 验证范围

- 累计功能基线已通过 Debug 与未签名 Release 编译、Debug Android 测试 APK 编译、Android Lint、注册基线验证、公开源码边界检查、双语资源键一致性，并明确确认已退役的 ROM Context Probe 不存在于正常源码和 Debug APK 中。
- 已记录的 AYN Thor 机主实机检查覆盖：动态 Canvas 导入/播放/生命周期与 Profile Bundle 恢复；Startup Readiness 与 First Setup；无障碍/Shizuku 独立状态；高级控制权限与服务状态；无手柄、原生和 Xbox 模式下的录制/回放；精准瞄准、右摇杆、增强触控、虚拟鼠标、PC 键盘及已支持自动游戏识别的冒烟路径；设置页显示；以及宏数字步进器可读性。
- 编译/静态结果与此前 Debug APK 验收不能替代真实签名 `0.2.1-alpha.1` 候选包验收。公开发布前仍须在 Thor 上完成该精确签名 APK 的版本专项矩阵。

### 已知限制

- Heimdall 面向 AYN Thor，不保证兼容所有固件、手柄模式、游戏、模拟器、PC 串流客户端或其他双屏设备。
- 模拟器 Profile 自动匹配继续采用保守策略。RetroArch 仍是候选路线：在 RetroArch 写入当前历史记录前，外部启动身份可能保持未知；Heimdall 不会把陈旧历史、菜单操作或任意无障碍文字当作有效证明。PPSSPP Gold 与更长时间的 Eden/键盘驻留覆盖少于已记录的核心冒烟测试。
- 高级控制要求 Shizuku 已安装、运行并授权。Heimdall 不会自动请求该权限；原生能力不可用时会明确关闭，不会静默切换为语义不同的路线。
- GIF 和动态 WebP 要求 Android 9 或更高版本。MP4 始终静音循环。动态 Canvas 文件上限为 50 MiB，每个 Profile 最多一个；不支持 APNG。
- PC 键盘使用固定 US ANSI 布局，是游戏中的 PC 输入工具，不是 Android 文字输入。Android 串流客户端可能无法转发外部 Meta/Win 输入；需要 Win 时请使用客户端内置键盘。
- 每个 Profile 当前支持一个实时放大镜，且不能与录屏同时占用 MediaProjection。
- Android 平台备份仍处于关闭状态。卸载或替换设备数据前，请把导出的 Profile Bundle 保存在 App 外部。
