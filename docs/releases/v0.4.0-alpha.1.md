# Heimdall 0.4.0 Alpha 1 Release Notes

Release tag: `v0.4.0-alpha.1`

[English](#english) | [简体中文](#简体中文)

## English

### Updating

- Install this official Alpha over an existing official Heimdall Alpha. Uninstalling first removes local App data.
- Export important Profiles and keep the `.heimdall-profile` bundles outside the App until the update has been checked. Provider API keys are not included in Profile exports.

### What's New

- **Portals:** A Profile can place up to two live upper-screen Portals. Each keeps its own region, zoom, shape, frame rate, freeze state, and View Only or Interactive mode. Both share one Android screen-capture session. Interactive mode uses Shizuku Enhanced Touch to map one-finger input to the visible upper-screen region; only one Portal gesture is active at a time. Portal and recording remain mutually exclusive.
- **Community Profiles:** Browse the curated catalog, preview an entry, and download a self-contained Profile bundle. Heimdall checks its size and SHA-256, validates it through the existing importer, and adds it as a new Profile without replacing existing ones.
- **Translation:** Provider credentials are isolated when switching between SiliconFlow and custom OpenAI-compatible services. DeepSeek's supported non-thinking request path and Profile-owned text size and line-spacing controls are included. A successful connection test still requires the Settings footer Save before the configuration becomes active.
- **Reliability and size:** The Thor joystick-lighting path now follows the observed stock two-node protocol. Runtime work is parked while the screen is asleep, and the ordinary APK targets ARM devices with Release code and resource shrinking. No battery-life percentage is claimed from the available overnight observations.
- **Guide and Map fixes:** Long TXT imports use the bounded Guide text loader, and removing the final imported local map no longer restores it from legacy Profile fields.

### Privacy and Requirements

- Community Profiles fetch a curated catalog, previews, and bundles over HTTPS. Opening the catalog does not upload existing Profiles. See [Privacy](../PRIVACY.md) and the [catalog contract](../COMMUNITY_PROFILE_CATALOG_V1.md).
- Portal viewing requires Android screen-capture consent. Interactive input additionally requires authorized Shizuku and a usable Enhanced Touch route. Translation captures the selected upper-screen region through Heimdall Accessibility, performs OCR on-device, and sends recognized text to the player-selected HTTPS provider.

### Known Limitations

- Heimdall targets AYN Thor; other firmware, controller modes, games, emulators, streaming clients, and dual-screen devices are not guaranteed.
- Interactive Portals support one finger and one active Portal gesture at a time. Portals cannot run alongside screen recording. After a page round trip, a frozen Portal's Stop marker may occasionally be absent, or the last frame may remain visible after stopping.
- Automatic Profile matching stays conservative. RetroArch and PPSSPP Gold retain pending or limited coverage; ambiguous evidence never triggers a switch.
- Theme-matched joystick lighting remains experimental and off by default. If a ring shows a stale color or remains lit, use Thor's system lighting controls to restore or disable it.
- Translation quality and availability depend on the OCR script, network, model, and provider. API keys are App-global, encrypted locally, and excluded from Profile exports. Android platform backup remains disabled; keep exported bundles outside the App before uninstalling.

## 简体中文

### 更新说明

- 可直接覆盖安装到现有的官方 Heimdall Alpha。先卸载会清除应用本地数据。
- 更新前导出重要 Profile，并将 `.heimdall-profile` 迁移包保存在 App 外部，直到确认更新正常。Profile 导出不包含翻译服务的 API Key。

### 本版改进

- **界门：** 一个 Profile 最多可放两个实时上屏界门。每个界门分别保存区域、缩放、形状、帧率、冻结状态及“仅观看”或“可交互”模式，共用一次 Android 屏幕捕获。可交互模式通过 Shizuku 增强触控把单指输入映射到可见的上屏区域；同时只能有一个界门手势。界门与录屏仍互斥。
- **社区 Profile：** 浏览精选目录、预览条目并下载自包含的 Profile 迁移包。Heimdall 校验字节大小和 SHA-256，再通过已有导入器验证，并追加为新 Profile，不替换现有 Profile。
- **实时翻译：** 在 SiliconFlow 与自定义 OpenAI 兼容服务之间切换时分别保存凭据；加入 DeepSeek 支持的非思考请求路线，以及 Profile 级字号和行距设置。连接测试成功后仍需点击设置页底部的“保存”，配置才会生效。
- **可靠性与体积：** Thor 摇杆灯改用已观察到的原厂双节点协议。屏幕休眠时暂停相关运行工作；普通 APK 面向 ARM 设备，Release 启用代码和资源压缩。现有过夜观察不足以宣称具体省电百分比。
- **攻略与地图修复：** 长 TXT 导入使用有界的攻略文本加载器；删除最后一张导入的本地地图后，不会再从旧 Profile 字段恢复该条目。

### 隐私与使用条件

- 社区 Profile 通过 HTTPS 获取精选目录、预览和迁移包；打开目录不会上传已有 Profile。详见[隐私说明](../PRIVACY.zh-CN.md)和[目录约定](../COMMUNITY_PROFILE_CATALOG_V1.md)。
- 观看界门需要 Android 屏幕捕获授权；可交互输入还需要已授权的 Shizuku 与可用的增强触控路线。翻译通过 Heimdall 无障碍服务捕获选定上屏区域，在本机完成 OCR，再把识别文字发送给玩家选择的 HTTPS 服务。

### 已知限制

- Heimdall 面向 AYN Thor，不保证兼容其他固件、手柄模式、游戏、模拟器、串流客户端或双屏设备。
- 可交互界门只支持单指，且同时只能有一个界门手势；界门不能与录屏并行。从其他页面返回后，冻结界门的 Stop 标记偶尔可能缺失，停止后也可能保留最后一帧。
- Profile 自动匹配保持保守。RetroArch 与 PPSSPP Gold 仍有待验证或有限覆盖；证据有歧义时不会自动切换。
- 主题匹配摇杆灯仍为实验性功能，默认关闭。如灯环残留旧色或继续亮起，请使用 Thor 原厂灯光设置恢复或关闭。
- 翻译质量和可用性取决于 OCR 文字类型、网络、模型及服务商。API Key 是 App 全局设置，在本机加密，不进入 Profile 导出。Android 平台备份仍关闭；卸载前请把导出包保存在 App 外部。
