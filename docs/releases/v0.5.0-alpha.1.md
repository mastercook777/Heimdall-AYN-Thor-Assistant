# Heimdall 0.5.0 Alpha 1 Release Notes

Release tag: `v0.5.0-alpha.1`

[English](#english) | [简体中文](#简体中文)

## English

### Updating

- Install this official Alpha over an existing official Heimdall Alpha. Uninstalling first removes local App data.
- Export important Profiles and keep the `.heimdall-profile` bundles outside the App until the update has been checked. Provider API keys are not included in Profile exports.

### What's New

- **Gallery and Canvas:** The Gallery now groups Profile maps, newly indexed screenshots, and saved Canvas images. Images can be sent to an existing Canvas through its composition editor. Canvas can also rotate through a saved set of images; its slideshow timing stays aligned across Canvas widgets.
- **Guide reader:** Search the full text of a local Note, TXT, or Markdown guide and jump through its detected chapter headings. The earlier Guide Peek Home widget was withdrawn and is not in this release.
- **Controls and layout:** Virtual Mouse can use a movement-only mode or enable gestures, including an optional three-finger middle click. Macros can repeat with a chosen time limit and the same button stops them. Grid Add makes room in a crowded layout preview while keeping Save/Discard explicit. About Heimdall shows the creator and support link.
- **Desktop Profile:** Choose one existing Profile as the fallback for a confirmed unbound upper-screen app or launcher. The Profile switcher provides a Return to Desktop action. Manual Profile selection remains in place until the upper-screen app or a confirmed game changes; ambiguous recognition does not force a switch.
- **Quick Actions:** Choose shortcut actions and optional media controls, linked dual-screen brightness, and media volume for each Profile. The module reflows with its selected capabilities; the full set fits a 4 × 6 Grid area on the tested Thor layout. Media controls use Android's active media sessions, include a player switcher, and can open a launchable player on the upper screen. The speaker icon toggles mute. Linked brightness requires an available Thor Direct connection and manual brightness mode.
- **Thor Direct:** On supported AYN Thor firmware, an optional direct connection now provides the native controller and upper-screen input routes previously requiring Shizuku. Shizuku remains available as a fallback and for other devices. Thor Direct is experimental and can become unavailable if the firmware's service changes.
- **Profile binding:** Choose an app by name from recently detected or installed apps. The editable package-name field has been removed; the chosen app and game-context binding still take effect only after Settings Save.

### Privacy and Requirements

- Media controls require Android notification access and a compatible active media session. A player that does not expose a usable session or action may offer limited controls. Selecting a player does not guarantee that a background app can start playback.
- Linked brightness uses Heimdall's opt-in Thor Direct helper on the two recognized physical Thor displays. It is unavailable when that route is not ready or automatic brightness mode is active.
- Thor Direct does not change the existing permissions for Basic Touch or Android screen capture. See [Privacy](../PRIVACY.md) and the [setup guide](../../README.md).

### Known Limitations

- Heimdall targets AYN Thor; other firmware, controller modes, games, emulators, streaming clients, and dual-screen devices are not guaranteed.
- Automatic Profile matching remains conservative. RetroArch and PPSSPP Gold retain pending or limited coverage; ambiguous evidence never triggers a switch.
- Media controls depend on each app's MediaSession behavior. Some apps require playback to be started inside that app before Heimdall can control it.
- The Gallery indexes only new Heimdall screenshots for a Profile; removing a Gallery reference does not delete its original file. Guide search and chapters apply to local text, not PDF or web links.
- About's online supporter list will remain empty until consenting names are published; its creator and support information work independently.
- The Grid and Profile editors still require explicit Save. Export Profiles before uninstalling; Android platform backup remains disabled.

## 简体中文

### 更新说明

- 可直接覆盖安装到现有的官方 Heimdall Alpha。先卸载会清除应用本地数据。
- 更新前导出重要 Profile，并将 `.heimdall-profile` 迁移包保存在 App 外部，直到确认更新正常。Profile 导出不包含翻译服务的 API Key。

### 本版改进

- **图库与画布：** 图库按当前 Profile 展示地图、新建立索引的截图和已保存的画布图片。可将图片送入现有画布的编辑器；画布还可轮播已保存的多张图片，多个画布的轮播时间保持同步。
- **攻略阅读：** 可搜索本地笔记、TXT、Markdown 攻略全文，并通过识别出的章节标题跳转。此前试做的主页 Guide Peek 小组件已回退，不包含在本版中。
- **操控与布局：** 虚拟鼠标可只移动指针，或开启手势及可选的三指中键。宏可按选定时限循环，再按同一个按钮停止。Grid 在拥挤的草稿中添加模块时会尝试腾出空间，仍须明确保存或放弃。“关于 Heimdall”展示作者和支持链接。
- **桌面 Profile：** 可将一个现有 Profile 设为桌面回退页。当上屏应用或启动器已被可靠识别、且没有对应绑定时，Heimdall 显示该 Profile；切换面板提供“返回桌面”。手动选择其他 Profile 后，会保持到上屏应用或明确识别的游戏发生变化；有歧义的识别结果不会强制切换。
- **快捷操作：** 每个 Profile 可选择快捷按钮和媒体控制、双屏联动亮度、媒体音量等可选能力。模块会随所选能力调整布局；全部开启时，在已测试的 Thor 布局中可使用 4 × 6 格。媒体控制使用 Android 当前媒体会话，提供播放器切换，并可在上屏打开可启动的播放器；点击喇叭图标可静音或恢复。双屏亮度需要可用的 Thor 直连及手动亮度模式。
- **Thor 直连：** 在受支持的 AYN Thor 固件上，可选的直连通道提供原先需要 Shizuku 的原生手柄与上屏输入能力。Shizuku 仍可作为备用方案，也可用于其他设备。Thor 直连仍为实验性能力，固件服务变化可能使其不可用。
- **Profile 绑定：** 可按名称从最近识别或已安装的应用列表选择绑定对象，移除了手填包名框。选中的应用及游戏上下文仍须点击设置页“保存”后才生效。

### 隐私与使用条件

- 媒体控制需要 Android 通知使用权和兼容的媒体会话。播放器未提供可用会话或动作时，控件能力可能受限。选中播放器不保证后台应用能够直接开始播放。
- 双屏联动亮度使用由玩家主动开启的 Thor 直连助手，仅作用于识别到的两块 Thor 实体屏。直连未就绪或系统处于自动亮度模式时不可用。
- Thor 直连不会改变基础触控或 Android 屏幕捕获原有的授权要求。详见[隐私说明](../PRIVACY.zh-CN.md)和[入门指南](../../README.zh-CN.md)。

### 已知限制

- Heimdall 面向 AYN Thor，不保证兼容其他固件、手柄模式、游戏、模拟器、串流客户端或双屏设备。
- Profile 自动匹配仍保持保守。RetroArch 与 PPSSPP Gold 仍有待验证或覆盖有限；证据有歧义时不会自动切换。
- 媒体控件依赖各 App 的 MediaSession 行为。某些 App 需要先在自身界面启动播放，Heimdall 才能控制。
- 图库只为当前 Profile 的 Heimdall 新截图建立索引；移除图库引用不会删除原文件。攻略搜索与章节适用于本地文本，不处理 PDF 或网页链接。
- “关于”里的在线支持者名单须待获得同意的昵称发布后才会显示；作者和支持信息不受影响。
- Grid 和 Profile 编辑仍须明确保存。卸载前请导出 Profile；Android 平台备份仍关闭。
