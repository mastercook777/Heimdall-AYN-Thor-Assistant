# Heimdall 0.2.0 Alpha 1 Release Notes

Release tag: `v0.2.0-alpha.1`

[English](#english) | [简体中文](#简体中文)

## English

### Update Guidance

- Install `0.2.0-alpha.1` directly over an existing official Heimdall Alpha. Do not uninstall first unless troubleshooting requires it; uninstalling removes local App data.
- Export important Profiles before updating. Keep the exported `.heimdall-profile` bundle outside the App until the updated Profiles and imported assets have been checked.
- After an Android or Shizuku state change, confirm that Shizuku is running and Heimdall remains authorized before using advanced input.

### Highlights

- Added a complete lower-screen PC keyboard through the established `Shizuku -> UserService -> uinput` route. The temporary US ANSI surface includes function keys, navigation, Numpad, host repeat, multi-touch chords, modifier latch/lock, and explicit Release All without using Android IME or changing the current Profile/Grid.
- Added a Profile-owned Keypad module with configurable key geometry and labels. Keypad keys may emit PC keyboard input or open the Full Keyboard, while component content and Grid placement keep separate explicit Save boundaries.
- Added a real relative Virtual Mouse through Shizuku/uinput, including movement, click, double-click drag, right-click, wheel, optional full gesture area, continuous session handling, and convergent button-up cleanup.
- Expanded Quick Actions into a configurable three-slot module with optional media volume and a closed action catalog.
- Completed the structured Macro workflow with a capability-matched controller sequence composer, directions and button chords, per-action holds, lossless recomposition, facing-direction mirroring, content-only macro cloning, bounded replay cancellation, and a single active dispatch gate that prevents queued duplicate runs.
- Improved Back focus handoff, Activity/controller extraction, Canvas runtime sharpness, Profile and Macro icon rendering, safe imported-icon deletion, and Freya White control materials without changing accepted Profile/Grid persistence contracts.

### Verification Scope

- The cumulative source passed the registered-baseline ancestry and feature-marker checks, public-source boundary verification, Debug APK assembly, Debug Android-test APK compilation, and Android Lint. Compiled Android tests are not reported as executed device tests.
- Recorded owner-operated AYN Thor checks cover Full Keyboard input, repeat, chords, modifiers, service/lifecycle cleanup, Steam Link, Moonlight, a PC emulator, grip and glare; Virtual Mouse click/drag/right-click/wheel and no-stuck behavior; Keypad and Quick Actions component Save; Back/Home ownership; icon and control presentation; and focused controller-composer recomposition, numeric timing, charge hold, mirroring, and Enhanced Touch cancellation.
- The real-signed `0.2.0-alpha.1` candidate still requires its release-specific update/install, signer, launch, persistence, Shizuku, keyboard, mouse, Macro, and cleanup acceptance pass on Thor before publication.

### Known Limitations

- Heimdall targets AYN Thor and does not guarantee compatibility with every firmware, controller mode, game, emulator, PC streaming client, or other dual-screen device.
- PC Keyboard and Virtual Mouse require a running, authorized Shizuku UserService and fail closed when that route is unavailable. Full Keyboard V1 uses a fixed US ANSI layout; it is PC input, not Android text-entry or IME replacement.
- Controller identity, event path, D-pad representation, and right-stick axes are capability-resolved. The broader structured-composer matrix across native and Xbox-compatible modes remains title- and mode-dependent.
- Enhanced Touch controller-macro protection remains enabled by default for every Profile. Disable it only when Thor's built-in mapping is not in use; Heimdall cannot detect the vendor mapper state.
- One live magnifier is supported per Profile, and magnification cannot share MediaProjection with recording.
- Android platform backup remains disabled. Keep an exported `.heimdall-profile` bundle outside the App before uninstalling or replacing device data.

## 简体中文

### 更新说明

- 可将 `0.2.0-alpha.1` 直接覆盖安装到现有 Heimdall 官方 Alpha。除非排障需要，请勿先卸载；卸载会清除 App 本地数据。
- 更新前请导出重要 Profile，并将 `.heimdall-profile` 迁移包保存在 App 外部，直到确认新版中的 Profile 和导入资源均正常。
- Android 或 Shizuku 状态变化后，在使用高级输入前请确认 Shizuku 正在运行且 Heimdall 仍已获得授权。

### 主要改进

- 通过既有的 `Shizuku -> UserService -> uinput` 路线新增完整下屏 PC 键盘。临时 US ANSI 键盘包含功能键、导航区、数字小键盘、主机重复、多点组合键、修饰键锁定和明确的 Release All；它不使用 Android IME，也不改写当前 Profile 或 Grid。
- 新增 Profile 级小键盘模块，可配置按键几何与显示内容。按键既可发送 PC 键盘输入，也可打开完整键盘；组件内容与 Grid 位置继续使用相互独立的明确保存边界。
- 新增经 Shizuku/uinput 输出的真实相对鼠标，支持移动、单击、双击拖动、右键、滚轮、可选全手势区域、连续会话，以及统一收敛到抬键的清理路径。
- 快捷操作扩展为可配置的三个动作槽，可选媒体音量，并使用封闭的动作目录。
- 完整化结构化宏工作流：新增按当前手柄能力匹配的序列编辑器、方向与组合按键、单动作蓄力、无损重新编辑、朝向镜像、只复制内容的宏克隆、有边界的回放取消，以及阻止重复排队执行的单一调度门。
- 改进返回键焦点交还、Activity/控制器拆分、Canvas 运行时清晰度、Profile 与宏图标渲染、安全删除导入图标，以及 Freya White 控件材质；已接受的 Profile/Grid 持久化边界保持不变。

### 验证范围

- 累计源码已通过注册基线祖先与功能标记检查、公开源码边界检查、Debug APK 编译、Debug Android 测试 APK 编译和 Android Lint。已编译的 Android 测试不等于已在设备上执行。
- 已记录的 AYN Thor 机主实机检查覆盖：完整键盘输入、重复、组合键、修饰键、服务/生命周期清理、Steam Link、Moonlight、PC 模拟器、握持与眩光；虚拟鼠标点击/拖动/右键/滚轮与无残留；小键盘和快捷操作组件保存；Back/Home 所有权；图标与控件显示；以及手柄宏编辑器的重新编辑、数字时间输入、蓄力、镜像和增强触控取消路径。
- 在公开发布前，仍需针对真实签名的 `0.2.0-alpha.1` candidate 在 Thor 上完成本版本的覆盖安装、签名、启动、持久化、Shizuku、键盘、鼠标、宏和清理验收。

### 已知限制

- Heimdall 面向 AYN Thor，不保证兼容所有固件、手柄模式、游戏、模拟器、PC 串流客户端或其他双屏设备。
- PC 键盘和虚拟鼠标要求 Shizuku UserService 正在运行且已授权；路线不可用时会关闭输出。完整键盘 V1 使用固定 US ANSI 布局，它是 PC 输入工具，不是 Android 文字输入或 IME 替代品。
- 手柄身份、事件路径、方向键表达和右摇杆轴按设备能力动态解析。结构化编辑器在原生/Xbox 兼容模式下的完整矩阵仍取决于具体模式与游戏。
- 每个 Profile 的增强触控手柄宏保护默认开启。只有在 Thor 自带映射未使用时才应主动关闭；Heimdall 无法检测厂商映射状态。
- 每个 Profile 当前支持一个实时放大镜，且不能与录屏同时占用 MediaProjection。
- Android 平台备份仍处于关闭状态。卸载或替换设备数据前，请把导出的 `.heimdall-profile` 迁移包保存在 App 外部。
