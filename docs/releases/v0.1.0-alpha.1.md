# Heimdall 0.1.0 Alpha Release Notes

Release tag: `v0.1.0-alpha.1`

[English](#english) | [简体中文](#简体中文)

## English

### What Heimdall Is

Heimdall is an always-open lower-screen assistant for AYN Thor. It keeps macros, touchpad and right-stick controls, maps, guides, static-image Canvases, magnification, and quick actions on the lower screen while the game remains on the upper screen.

This Alpha targets real-device testing on AYN Thor. It does not claim support for other dual-screen devices, every Thor firmware, or every game and emulator.

### Highlights

- Profiles own macros, Grid layouts, touch settings, maps, guides, static-image Canvases, and App bindings.
- Three 6 x 8 default Grids designed and verified on Thor: Balanced, Controls, and Macros.
- Direct visual Grid editing with drag, resize, grid snapping, preview, and explicit Profile save.
- Touch macros plus physical-controller macro recording, editing, and replay.
- Basic Touch uses Accessibility for upper-screen taps, holds, swipes, and touchpad drags.
- Controller Enhancement uses Shizuku for physical-controller recording/replay, Virtual Right Stick, and Precision Aim.
- On the tested Thor firmware, Shizuku Touch can coexist with Thor's built-in key mapping without cancelling either touch stream.
- In Enhanced Touch mode, tap, hold, swipe, and wait macros use the mapping-compatible touch route; macros containing physical-controller steps ask the player to switch touch mode before replay.
- Upper-screen screenshots, recording, a live region magnifier, Profile maps, and guides.
- Multiple independent static-image Canvases per Profile, with Fit / Fill composition and full-screen viewing.
- English and Simplified Chinese, with Heimdall Blue and Freya White appearances.

### Setup And Permissions

- Basic Touch requires the Heimdall Accessibility service.
- Controller Enhancement, physical-controller recording/replay, Virtual Right Stick, Precision Aim, and mapping-compatible Shizuku Touch require Shizuku to be installed, running, and authorized.
- The live upper-screen magnifier and recording require Android MediaProjection consent.
- Game-audio recording requests audio permission but uses Android Audio Playback Capture rather than microphone input. The upper App may still forbid playback capture.
- Profile data stays on the device unless the player explicitly imports or exports it. Android platform backup is disabled for this Alpha.

### Known Limitations

- Mapping-compatible Shizuku Touch is verified only on the tested Thor, firmware, game, and mapping configuration. It requires a strictly identified upper touchscreen and Thor vendor touch bridge. Other firmware may report the feature unavailable or use compatible touch fallback; coexistence must not be assumed. Enhanced Touch screen macros do not use that fallback.
- Basic Accessibility touch and Thor's built-in mapper use separate touch streams and can cancel each other when used simultaneously. Use the verified Shizuku Touch route when coexistence is required.
- Thor's built-in mapper may hide mapped physical buttons from Heimdall's recording stream. Temporarily return to the system Home screen to record those buttons. Enhanced Touch mode does not replay physical-controller steps; switch touch mode before using those macros.
- Controller event paths and right-stick axes are resolved dynamically by device identity and capabilities; no fixed `event` number is used. Public Alpha coverage still needs more Thor native-mode, Xbox-mode, and firmware combinations.
- Android capture consent, the system document picker, or lower-screen text input can temporarily move focus away from the upper game. On the tested Thor / Eden setup, one upper-screen touch restored full frame rate.
- Game-audio capture works only when the upper App permits Android Audio Playback Capture.
- One live magnifier is supported per Profile, and magnification cannot share MediaProjection with recording.
- After switching from another lower-screen tab back to Main, double-tap freeze can omit the top-right Stop marker. After repeated interruption/resume and rapid tab switching, stopping magnification can leave the last retained frame visible instead of returning the module to black. These are presentation-state issues; the accepted Alpha test did not reproduce A-005 black live output or another projection-consent request.
- The public Alpha package is `com.mastercook777.heimdall`; new Debug builds use `com.mastercook777.heimdall.debug`. They can coexist but do not share App data. The older pre-correction test build is also a separate App and cannot update into the public Alpha. Export all Profiles before migration and import them after installing Alpha.
- The current Profile export is configuration JSON and does not contain custom Profile icon files, user-imported Macro icon files, or Canvas image files. Select or import those assets again after migration.

### Helpful Bug Reports

Please include the Thor firmware version, controller mode (native or Xbox), game or emulator, active connection route (Basic Touch or Shizuku), reproducible steps, and screenshots or recordings when possible.

## 简体中文

### Heimdall 是什么

Heimdall 是为 AYN Thor 下屏设计的常驻游戏助手。它让玩家在不离开上屏游戏的情况下，通过下屏使用宏、触摸板、右摇杆控制、地图、攻略、静态画布、放大镜和快捷操作。

本 Alpha 面向 AYN Thor 实机测试，不承诺支持其他双屏设备、所有 Thor 固件或所有游戏与模拟器。

### 主要功能

- Profile：为不同游戏保存宏、Grid 布局、触摸设置、地图、攻略、静态画布和应用绑定。
- 三套 Thor 实机设计的 6 x 8 默认 Grid：平衡、操控、宏。
- 可视化 Grid 编辑：拖动、缩放、吸附到网格；只有明确保存后才写入当前 Profile。
- 触控宏与实体手柄宏的录制、编辑和回放。
- 基础触控：通过无障碍服务向上屏发送点击、长按、滑动和触摸板拖动。
- 控制器增强：通过 Shizuku 使用实体手柄录制/回放、虚拟右摇杆和精准瞄准。
- Shizuku 触控：在已测试的 Thor 固件上，可与 Thor 自带按键映射同时使用而不互相取消触摸。
- 增强触控模式下，点击、长按、滑动和等待宏使用映射兼容触控通道；包含实体手柄步骤的宏会在执行前提示切换触控模式。
- 上屏截图、录屏、局部实时放大镜，以及 Profile 内的地图和攻略。
- Profile 内可放置多个独立的静态图片 Canvas，支持 Fit / Fill 构图和全屏查看。
- English / 简体中文，以及 Heimdall Blue / Freya White 两套外观。

### 首次使用与权限

- 基础触控需要启用 Heimdall 无障碍服务。
- 控制器增强、实体手柄录制/回放、虚拟右摇杆、精准瞄准和映射兼容的 Shizuku 触控需要安装、运行并授权 Shizuku。
- 上屏放大镜和录屏需要 Android 的 MediaProjection 屏幕捕获授权。
- 游戏声音录制需要录音权限，但 Heimdall 使用的是 Android Audio Playback Capture，不采集麦克风；上屏应用仍可禁止自身声音被捕获。
- Profile 数据保存在本机。导入和导出只在玩家主动操作时进行。Alpha 默认关闭 Android 平台备份。

### 已知限制

- 映射兼容的 Shizuku 触控目前只在已测试的 Thor、固件、游戏和按键映射组合上完成实机验证。它依赖严格识别的 Thor 上屏触摸设备和厂商触控桥；其他固件若不提供相同接口，功能会显示不可用或回退到兼容触控，不应被视为已支持共存。增强触控屏幕宏不会回退到兼容触控。
- 基础无障碍触控与 Thor 自带按键映射来自不同触摸流；两者同时操作时可能互相取消。需要共存时请使用已验证可用的 Shizuku 触控。
- Thor 自带按键映射可能使已映射的实体按键不进入 Heimdall 录制流。录制这类按键时，请暂时返回系统桌面完成录制。增强触控模式不会回放实体手柄步骤；需要使用这类宏时请切换触控模式。
- 实体手柄设备路径和右摇杆轴会按名称与能力动态识别，不固定使用某个 `event` 编号。公开 Alpha 仍需要扩大 Thor 原生模式、Xbox 模式和不同固件的测试覆盖。
- Android 的屏幕捕获授权、系统文件选择器或下屏文字输入有时会临时转移上屏焦点。在已测试的 Thor / Eden 上，触摸一次上屏即可恢复帧率。
- 录制游戏声音取决于上屏应用是否允许 Audio Playback Capture。
- 每个 Profile 当前支持一个实时放大镜；实时放大和录屏不能同时占用 MediaProjection。
- 从其他下屏 Tab 切回 Main 后，双击暂停可能不显示右上角的 Stop 标记；反复中断/恢复并快速切换 Tab 后停止放大镜，模块可能保留停止前的最后一帧，而不是恢复为黑色。这两项属于显示状态问题；已验收的 Alpha 测试没有再次出现 A-005 的实时画面黑屏或重新索取投影权限。
- 公开 Alpha 的包名是 `com.mastercook777.heimdall`，新的 Debug 包名是 `com.mastercook777.heimdall.debug`，两者可以共存但不会共享数据。更早的预修正测试包也是独立应用，不能直接升级为公开 Alpha。迁移前请导出全部 Profile，安装 Alpha 后再重新导入。
- 当前 Profile 导出是配置 JSON，不包含自定义 Profile 图标、用户导入的 Macro 图标或 Canvas 图片文件。迁移后需要重新选择或导入这些资源。

### 反馈建议

报告问题时，请尽量附上：

- Thor 固件版本和手柄模式（原生 / Xbox）。
- 游戏或模拟器名称。
- 使用的连接方式（基础触控 / Shizuku）。
- 可重复的操作步骤、截图或录屏。
- 问题是否在重启 Heimdall 或重新授权后仍可复现。
