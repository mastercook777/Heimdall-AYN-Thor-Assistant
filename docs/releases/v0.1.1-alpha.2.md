# Heimdall 0.1.1 Alpha 2 Hotfix

Release tag: `v0.1.1-alpha.2`

[English](#english) | [简体中文](#简体中文)

## English

### Update Guidance

- Install `0.1.1-alpha.2` directly over the existing public Alpha. Do not uninstall first unless troubleshooting requires it; uninstalling removes local App data.
- Export important Profiles before updating.
- After an Android or Shizuku state change, confirm that Shizuku is running and Heimdall remains authorized.

### Stability Hotfix

- Fixed a Public Alpha ANR path that could freeze Heimdall after a fresh install and first-time Shizuku setup, especially on the first Enhanced Touch gesture.
- UserService binding now starts away from the Android UI thread. The UI thread is also prohibited from waiting for the Shizuku connection latch.
- Enhanced Touch, Precision Aim, and Virtual Right Stick now share explicit binding, connected, disconnected, Binder-dead, and timeout handling.
- An input gesture that arrives while the UserService is still connecting is dropped safely. Heimdall may show a short getting-ready status; retry after the connection completes.
- Binder death, service disconnection, and bind timeout clear the stale connection state so a later input attempt can reconnect.

### Preserved Behavior

- This hotfix does not change the Thor vendor `/dev/rstouch` route, touch coordinates, Precision Aim or right-stick output curves, physical-controller discovery, Profile data, Accessibility fallback boundaries, or App-aware Profile matching.
- App-aware recognition problems remain a separate issue and are not treated as the same root cause as this ANR.

### Verification Scope

- The exact runtime patch passed Debug and Release compilation, Debug Android-test compilation, static route assertions, and Android Lint with zero errors.
- On AYN Thor, the owner repeatedly uninstalled and reinstalled the hotfix Debug package, restarted and authorized Shizuku, and exercised Enhanced Touch, Precision Aim, and Virtual Right Stick through first touch, rapid repeated touch, leave/return, and Profile-switch continuation. No UI freeze or ANR was observed.
- The getting-ready status did not appear during those runs because proactive binding completed before the tested first gestures.

### Known Limitations

- Heimdall targets AYN Thor and does not guarantee compatibility with every firmware, controller mode, game, emulator, or other dual-screen device.
- Mapping-compatible Enhanced Touch still depends on Thor's tested vendor touch route and an authorized Shizuku UserService.
- If Shizuku is stopped, authorization is missing, or the UserService is still connecting, advanced input remains temporarily unavailable and does not fall back to a route with different semantics.
- Android platform backup remains disabled. Keep an exported `.heimdall-profile` bundle outside the App before uninstalling or replacing device data.

## 简体中文

### 更新说明

- 可将 `0.1.1-alpha.2` 直接覆盖安装到现有公开 Alpha。除非排查问题需要，否则请勿先卸载；卸载会清除 App 本地数据。
- 更新前请先导出重要 Profile。
- Android 或 Shizuku 状态发生变化后，请确认 Shizuku 正在运行且 Heimdall 仍已获得授权。

### 稳定性热修复

- 修复公开 Alpha 在删除重装并首次配置 Shizuku 后可能导致 Heimdall 冻结和 ANR 的路径，尤其是增强触控第一次触摸时。
- UserService 绑定现在只在 Android UI 线程之外启动，同时禁止 UI 线程等待 Shizuku 连接锁存器。
- 增强触控、精准瞄准和虚拟右摇杆现在共用明确的正在绑定、已连接、已断开、Binder 死亡和超时状态处理。
- 如果 UserService 尚在连接时收到输入手势，本次手势会安全丢弃。Heimdall 可能短暂显示“正在准备中”，连接完成后重试即可。
- Binder 死亡、Service 断连或绑定超时会清除过期连接状态，后续输入可以重新发起连接。

### 保持不变的行为

- 本 hotfix 不修改 Thor 厂商 `/dev/rstouch` 路由、触控坐标、精准瞄准或右摇杆输出曲线、实体手柄发现、Profile 数据、无障碍回退边界或 App-aware Profile 匹配逻辑。
- App-aware 识别问题仍作为独立问题处理，不与本次 ANR 强行归为同一根因。

### 验证范围

- 完全相同的运行时补丁已通过 Debug 与 Release 编译、Debug Android 测试 APK 编译、静态路径断言，以及零错误的 Android Lint。
- 在 AYN Thor 上，机主反复卸载并重装 hotfix Debug 包，重新启动和授权 Shizuku，并分别测试增强触控、精准瞄准和虚拟右摇杆的第一次触摸、连续快速触摸、离开后返回以及切换 Profile 后继续操作；未观察到界面冻结或 ANR。
- 这些测试中没有出现“正在准备中”提示，因为后台预绑定已在首次测试手势前完成。

### 已知限制

- Heimdall 面向 AYN Thor，不保证兼容所有固件、手柄模式、游戏、模拟器或其他双屏设备。
- 映射兼容的增强触控仍依赖已测试的 Thor 厂商触控路由和已授权的 Shizuku UserService。
- 如果 Shizuku 未运行、尚未授权或 UserService 仍在连接，高级输入会暂时不可用，并且不会回退到语义不同的输入路线。
- Android 平台备份仍处于关闭状态。卸载或替换设备数据前，请把导出的 `.heimdall-profile` 迁移包保存在 App 外部。
