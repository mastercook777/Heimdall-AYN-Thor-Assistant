# Heimdall 0.3.0 Alpha 1 Release Notes

Release tag: `v0.3.0-alpha.1`

[English](#english) | [简体中文](#简体中文)

## English

### Update Guidance

- Install `0.3.0-alpha.1` directly over an existing official Heimdall Alpha. Do not uninstall first unless troubleshooting requires it; uninstalling removes local App data.
- Export important Profiles before updating and keep the `.heimdall-profile` bundles outside the App until the update has been checked.
- Existing 6 x 8 layouts migrate to the 12 x 8 Grid. Review each important Profile before saving further layout changes.
- Translation is optional. It requires Heimdall Accessibility for upper-screen capture plus a player-configured API key and network service; it does not require Shizuku or MediaProjection.

### Highlights

- Expanded the Profile Grid from 6 x 8 to 12 x 8 for finer placement while preserving direct drag/resize interaction, preview-first editing, explicit Grid Save, and legacy layout migration.
- Added six governed Heimdall and Freya colorways with shared family materials, semantic states, optional per-Profile theme binding, and a standalone browser Theme Lab for colorway development.
- Added experimental theme-matched Thor joystick lighting. The App-global switch is off by default, uses one shared brightness, and keeps theme behavior independent when the firmware route is unavailable.
- Added one Profile-owned Translation Widget with a selectable upper-screen region, on-device Latin/Chinese/Japanese/Korean ML Kit OCR, target-language control, stable duplicate suppression, and one bounded HTTPS translation request lane. A successful provider connection test now gives visible confirmation.
- Added App-global SiliconFlow China/Global and custom OpenAI-compatible `/chat/completions` settings. API keys are encrypted with Android Keystore and are excluded from Profile data and exports.
- Added one passive Hardware Monitor per Profile. It reads the uniquely identified ordinary-App `cpu-0-1` thermal source and Android RAM information, pauses outside active Main use, and fails closed instead of substituting battery temperature or estimating fan speed. The Freya-family two-row presentation has been compacted without changing the Heimdall-family layout.
- Added GameNative current-state Profile matching for supported PC-game launches, while keeping the conservative resolver, manual-selection protection, and ambiguity-no-switch rule.
- Refined Canvas fill bounds, magnifier interaction, component surfaces, English terminology, compact-control fit, and visual consistency without changing the established Profile/Grid Save boundaries.

### Privacy And Network

- Translation screenshots are processed locally for OCR. Heimdall sends recognized text, the requested target language, and a short translation instruction - not the screenshot - to the provider selected by the player.
- Bundled Google ML Kit performs OCR on-device. Google states that the SDK may still send diagnostics and utilization metrics such as device/App information and a per-installation identifier; see the public privacy document for the exact boundary.
- Provider privacy, retention, account, and billing terms apply. Custom endpoints must use HTTPS.
- Translation provider credentials are App-global, encrypted locally, and not included in Profile JSON or `.heimdall-profile` bundles. See [Privacy And Capability Boundary](../PRIVACY.md).

### Verification Scope

- The registered cumulative Debug baseline is clean at `e890301f26f13975d290dbc9fc546e9ce90687d1`; its reference APK is SHA-256 `81B993139B00367BEF525A9810F06057F21F65DAEBFCA711966A7DA74016B0E7`. Later recurrence supersedes that APK's earlier lighting-reliability acceptance but does not invalidate the other accepted baseline features.
- On exact Debug APK SHA-256 `3D9BA88D1541232B2A78E1381F8810CA97388CB603B9591EE56FDF65CFA7690B`, owner-operated Thor checks accepted the Freya-family Hardware Monitor at two-row height and visible Translation Test Connection success feedback. That APK did not resolve the joystick-lighting defect and was rejected as a complete release candidate.
- Build/static results and accepted Debug APK checks do not accept the real-signed `0.3.0-alpha.1` candidate. Before publication, the exact signed APK must still pass the release-specific Thor update/install, Profile migration, permissions, Translation, Grid, theme, input, magnifier, and cleanup matrix, with the documented experimental-lighting limitation confirmed as bounded and recoverable through Thor's system controls.

### Known Limitations

- Heimdall targets AYN Thor and does not guarantee compatibility with every firmware, controller mode, game, emulator, PC streaming client, translation provider, or other dual-screen device.
- Translation accuracy and latency depend on the selected OCR script, game font/layout, network, model, and provider. SiliconFlow China with Hunyuan-MT-7B is the owner-tested provider route; other listed and custom OpenAI-compatible endpoints are protocol-compatible but not all are Thor-validated.
- Only recognized text is sent for translation, but game dialogue, account names, or other selected text may still be sensitive. Select the region deliberately and review the configured provider's terms.
- Hardware Monitor shows CPU temperature only when Thor exposes one unique readable `cpu-0-1` thermal source to the ordinary App process. It intentionally reports unavailable on ambiguous or unreadable devices.
- Theme-matched joystick lighting is experimental and off by default. On the tested Thor firmware, a fixed segment near the upper-left of the left joystick can retain a stale/different color or remain lit after Theme, brightness, or switch changes. Turning the feature off inside Heimdall may not clear that segment immediately; use Thor's system lighting controls to restore or disable the lights. This is a known `0.3.0-alpha.1` limitation planned for follow-up investigation.
- Automatic Profile matching remains conservative. RetroArch and PPSSPP Gold retain the previously documented pending/limited coverage; Heimdall does not switch on ambiguous or stale evidence.
- Advanced Controls require Shizuku to be installed, running, and authorized. Unavailable native features fail closed instead of silently changing semantics.
- One live magnifier is supported per Profile, and magnification cannot share MediaProjection with recording.
- Android platform backup remains disabled. Keep exported Profile bundles outside the App before uninstalling or replacing device data.

## 简体中文

### 更新说明

- 可将 `0.3.0-alpha.1` 直接覆盖安装到现有 Heimdall 官方 Alpha。除非排障需要，请勿先卸载；卸载会清除 App 本地数据。
- 更新前请导出重要 Profile，并将 `.heimdall-profile` 迁移包保存在 App 外部，直到确认更新正常。
- 现有 6 x 8 布局会迁移到 12 x 8 Grid。继续保存布局修改前，请逐一检查重要 Profile。
- 实时翻译是可选功能。它需要 Heimdall 无障碍服务进行上屏捕获，并需要玩家配置 API Key 与网络服务；不需要 Shizuku 或 MediaProjection。

### 主要改进

- 将 Profile Grid 从 6 x 8 扩展为 12 x 8，提供更细的布局精度，同时保留直接拖动/缩放、先预览、明确保存和旧布局迁移规则。
- 新增六个受治理的 Heimdall/Freya 配色，保持 Family 材质与语义状态一致，支持可选的 Profile 主题绑定，并提供独立浏览器 Theme Lab 供配色开发使用。
- 新增实验性的 Thor 摇杆灯主题匹配。App 全局开关默认关闭，使用统一亮度；固件路线不可用时不影响主题本身。
- 新增每个 Profile 一个实时翻译模块：可选择上屏区域，在本机完成拉丁/中/日/韩 ML Kit OCR，选择目标语言，稳定抑制重复文字，并通过一个有界 HTTPS 请求通道翻译。翻译服务连接测试成功时现在会显示明确反馈。
- 新增 App 全局的 SiliconFlow 中国区/全球区与自定义 OpenAI 兼容 `/chat/completions` 设置。API Key 使用 Android Keystore 加密，不进入 Profile 数据或导出。
- 新增每个 Profile 一个被动硬件监控模块。它读取普通 App 可访问、唯一识别的 `cpu-0-1` 温度源和 Android 内存信息；离开活动 Main 后暂停，无法确认时显示不可用，不会拿电池温度代替或估算风扇转速。Freya Family 的两格高度布局已单独压缩，Heimdall Family 布局保持不变。
- 为受支持的 PC 游戏启动路径新增 GameNative 当前状态 Profile 匹配，同时保留保守解析、手动选择保护和歧义时不切换的规则。
- 改进 Canvas 填充边界、放大镜交互、组件材质、英文术语、紧凑控件适配和整体视觉一致性，同时保持既有 Profile/Grid 保存边界不变。

### 隐私与联网

- 翻译截图只在本机用于 OCR。Heimdall 会把识别出的文字、目标语言和简短翻译指令发送给玩家选择的服务，但不会发送截图本身。
- 内置 Google ML Kit 在本机执行 OCR。Google 说明该 SDK 仍可能发送诊断与使用指标，例如设备/App 信息和每次安装标识符；准确边界见公开隐私文档。
- 翻译服务商自己的隐私、保留、账户和计费条款仍然适用；自定义接口必须使用 HTTPS。
- 翻译服务凭据属于 App 全局设置，在本机加密保存，不会写入 Profile JSON 或 `.heimdall-profile` 迁移包。详见[隐私与能力边界](../PRIVACY.zh-CN.md)。

### 验证范围

- 已注册的累计 Debug 基线在 `e890301f26f13975d290dbc9fc546e9ce90687d1` 保持干净；其参考 APK SHA-256 为 `81B993139B00367BEF525A9810F06057F21F65DAEBFCA711966A7DA74016B0E7`。后续复现结果已推翻该 APK 对灯光可靠性的早期验收，但不影响基线中其他已接受功能。
- 机主已在 SHA-256 为 `3D9BA88D1541232B2A78E1381F8810CA97388CB603B9591EE56FDF65CFA7690B` 的精确 Debug APK 上接受 Freya Family 温控模块两格高度显示，以及翻译连接测试成功反馈。该 APK 未解决摇杆灯问题，因此不能作为完整发布候选。
- 编译/静态结果与已接受的 Debug APK 不能替代真实签名 `0.3.0-alpha.1` 候选包验收。公开发布前仍须在 Thor 上完成该精确签名 APK 的覆盖安装、Profile 迁移、权限、翻译、Grid、主题、输入、放大镜和清理矩阵，并确认已披露的实验性灯光问题范围可控、可通过 Thor 原厂灯控恢复。

### 已知限制

- Heimdall 面向 AYN Thor，不保证兼容所有固件、手柄模式、游戏、模拟器、PC 串流客户端、翻译服务或其他双屏设备。
- 翻译准确度与延迟取决于 OCR 文字类型、游戏字体/布局、网络、模型和服务商。机主验证的服务路线是 SiliconFlow 中国区配合 Hunyuan-MT-7B；其他列出的服务和自定义 OpenAI 兼容接口属于协议兼容，并非都完成 Thor 实机验证。
- 翻译只发送识别出的文字，但游戏对话、账户名或选区中的其他文字仍可能敏感。请谨慎选择区域，并查看所配置服务商的条款。
- 只有当 Thor 向普通 App 暴露唯一、可读的 `cpu-0-1` 温度源时，硬件监控才显示 CPU 温度；来源歧义或不可读时会明确显示不可用。
- 主题匹配摇杆灯为实验性功能，默认关闭。在已测试的 Thor 固件上，切换主题、亮度或开关后，左摇杆左上附近的一处固定灯段可能残留旧色、显示异色或继续亮起；在 Heimdall 内关闭功能也不一定立即清除。遇到异常时请使用 Thor 原厂灯光设置恢复颜色或关闭灯光。此问题作为 `0.3.0-alpha.1` 已知限制保留，后续版本将继续调查。
- Profile 自动匹配继续采用保守策略。RetroArch 与 PPSSPP Gold 保留此前记录的待验证/有限覆盖；Heimdall 不会根据歧义或陈旧证据切换。
- 高级控制要求 Shizuku 已安装、运行并授权。原生能力不可用时会明确关闭，不会静默切换为语义不同的路线。
- 每个 Profile 当前只支持一个实时放大镜；放大镜不能与录屏共享 MediaProjection。
- Android 平台备份仍处于关闭状态。卸载或替换设备数据前，请把导出的 Profile 迁移包保存在 App 外部。
