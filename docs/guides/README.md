# PDF Guide Archive

The English and Simplified-Chinese PDF files in this directory document earlier
Heimdall Alpha releases. Their layouts were visually reviewed and remain useful
as historical feature references, but they do not cover the 0.3.0 Translation,
Hardware Monitor, 12 x 8 Grid, Theme, or joystick-lighting features.

Use the repository [English README](../../README.md) or
[Simplified-Chinese README](../../README.zh-CN.md) for current 0.3.0 setup,
permissions, privacy, migration guidance, and known limitations. Versioned
release details remain under [`docs/releases`](../releases).
