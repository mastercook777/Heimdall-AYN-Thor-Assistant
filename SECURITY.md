# Security Policy

Heimdall Alpha is experimental software with Accessibility, MediaProjection,
and optional Shizuku capabilities. Install only APKs attached to versioned
releases in this repository and compare the published APK SHA-256 and signing
certificate SHA-256 before installation.

Do not disclose a suspected vulnerability in a public issue. Use the
repository's private security-advisory reporting flow after the public
repository is created. Do not send keystores, passwords, Profile exports, or
other private device data.

Only the latest published Alpha receives security fixes. Older Alpha builds and
mutable debug builds are unsupported.
